# 《异议处理实战》· 班主任（LP）微课

面向 **VIPTHINK 国内线上少儿数学思维班主任（LP）** 的互动式微课。内容源自《常见异议问题处理》培训 PPT（33 页），覆盖 7 类常见异议与异议处理四步法。

## 课程结构（6 章 · 学-练-考闭环）

| 章 | 主题 | 时长 | 形式 |
|---|---|---|---|
| 1 | 认识异议与四步法 | 8-10 分钟 | 图文 + 视频 + 3 题测验 |
| 2 | 效果类异议：「没看到效果」与「不想学了」 | 12-15 分钟 | 图文 + 视频 + 分型表格 + 3 题测验 |
| 3 | 时机类异议：「课时还多」与「时间不确定」 | 12-15 分钟 | 图文 + 视频 + **AI 家长沟通模拟练习** |
| 4 | 决策类异议：「爸爸不同意」 | 8-10 分钟 | 图文 + 视频 + 3 题测验 |
| 5 | 价值与产品类异议：「价格太贵」与「伤眼睛」 | 10-12 分钟 | 图文 + 视频 + 对比卡 + 3 题测验 |
| 6 | 终极考核：AI 家长自由对话 | 15-20 分钟 | 5 道综合选择题 + 3 道填空题 + AI 对话 + 四维评分 + 结业证书 |

完整设计说明见 [课程设计说明.md](./课程设计说明.md)。

## 互动机制

- **双重解锁规则**：进入下一章需**同时满足** ① **本章视频完整观看完毕**（播放至 95% 或播到结尾；进度条禁止拖动快进，拖动会拉回已看位置）② **本章任务完成**（选择题全部答对 / 第 3 章练习达标）
- **章节测验**：17 道选择题（第 1/2/4/5 章各 3 题 + 终极考核 5 道综合题），串行锁定，答对上一题才解锁下一题；答错可重做，不泄露正确答案
- **视频观看追踪**：每段视频显示 ⏳/✅ 观看角标，章首显示本视频进度条；观看位置本地保存，刷新后从上次位置继续
- **考核填空**：3 道填空题（终极考核），关键词作答，忽略空格与全角/半角标点，支持同义写法；答错只给知识点提示、可反复重填
- **AI 家长沟通模拟练习**：五维关键词覆盖评分（共情认同 / 确认与挖需 / 课程规划 / 时间与性价比 / 推进闭环）
- **终极考核**：5 道综合选择题 + 3 道填空题 + AI 自由对话（≥4 轮），AI 评分官按 **共情与关系 25 / 异议识别与诊断 25 / 方案与说服 30 / 闭环与合规 20** 四维评分
- **结业证书**：全部章节完成、三项考核全部通过后可填写姓名并打印
- **进度持久化**：刷新不丢失（含视频观看进度、答题记录、填空内容、对话记录与评分）

## 本地修改与重新构建

```bash
# 1) 改内容
#    编辑 _content.py（章节正文、题目、AI 提示词、评分维度）

# 2) 重新生成页面
python _build.py

# 3) 重新注入密钥（需要 .env，见 README-AI密钥说明.md）
node _build.js

# 4) 本地预览
node _server.js          # http://127.0.0.1:8123
```

改视频：编辑 `_video.py` 内的旁白文案与画面卡片，然后

```bash
python _video.py                # 全部重做
python _video.py --only ch1_v1  # 只重做某一段
```

## 安全说明

课程密钥采用 **XOR + hex 混淆** 注入，学员零填写。**混淆不是加密**——本仓库为公开仓库，如需「前端完全不含密钥」，请按 [WORKER-部署说明.md](./WORKER-部署说明.md) 切换到 Cloudflare Worker 代理模式。
